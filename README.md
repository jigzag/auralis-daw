# Auralis 0.4.42 — Windows Audio + MIDI Workstation

Windows 10/11 x64用の、ASIO入出力・音声／MIDI録音・ピアノロール・VST3ホスト・ミックス書き出しを備えたDAWの初期版です。Suno APIには依存しません。0.1で保存した音声プロジェクトも読み込めます。

## 起動

主要なメニュー・ボタン・操作説明・エラーは日本語で表示します。音声・MIDI機器の設定画面にも同じ日本語辞書を使います。トラック名・ファイル名・プロジェクトの保存形式は変更しません。

実行ファイル・タスクバー・ウィンドウには、Auralisの波形Aを使った専用アイコンを表示します。ショートカットのアイコンを指定する場合は、同梱の `Auralis.ico` を使えます。

`dist/Auralis/Auralis.exe` を起動します。更新後もこの起動先は同じです。Python・Node.js・追加インストーラーは不要です。実行ファイルと同じ場所の `Data` に音声機器設定を保存するので、書き込み可能な場所に展開してください。スキャンしたVST3一覧は、バージョン間で共通の `%APPDATA%/Auralis/plugins.xml` に保存します。生成したAuralisロゴは実行ファイルに埋め込んでいます。

更新版のZIPも常に `Auralis` フォルダを含みます。同じ場所へ展開すれば、起動先やショートカットを変えずに更新できます。アプリを閉じてから更新してください。`Data`・録音ファイル・プロジェクトは配布ZIPに含めず、既存のものを保持します。

開発用の `python tests/package.py` も固定の `dist/Auralis` を更新します。初回のみ、過去の版で最後に使った機器設定を移し、既存の録音を上書きせず不足ファイルを引き継ぎます。以降は同じDataを使い続けます。起動中の実行ファイルを更新できない場合は、現在のアプリとDataを変更せず中断します。過去の版のフォルダは自動削除しません。

## プロジェクトを開く際の安全確認

外部VSTを含むプロジェクトは、読み込み前にプラグイン名と実際のパスを表示します。**許可して開く** を選ぶまで外部VSTを実行しません。インサートがバイパス状態でも確認の対象です。内蔵EQ・チューナー・コンプレッサー・リバーブ・ディレイだけなら、この確認は不要です。外部VSTは通常のプログラムと同じ権限で動くため、信頼できるものだけ許可してください。

プロジェクトのフォルダ外にある素材は、解決後のパスを表示して今回の読み込みを確認します。キャンセルすると現在のプロジェクトを保持します。確認中にディスク上のプロジェクトが変更されても、確認した内容のスナップショットを読み込みます。承認済みの外部素材も、保存時には通常どおりプロジェクトの `_media` にコピーします。

ネットワーク共有・ネットワークドライブ・デバイスパス・代替データストリーム・シンボリックリンク／ジャンクションなどの再解析ポイント経由のプロジェクト・素材・プロジェクト内指定のVSTは読み込みません。対象を通常のローカルフォルダへコピーしてから開いてください。VST3バンドルの内部もリンク経由で外へ抜けないことを検査します。

読み込むプロジェクトはUTF-8 JSON（BOM可）、最大32 MiB・入れ子48段です。上限は128トラック、合計8192パート、MIDIノート10万・イベント10万、プラグイン128個（各チェーン32個）、プラグインの保存状態は1個8 MiB・合計16 MiBです。音声と波形キャッシュに使うメモリは、搭載メモリの4分の1・空きメモリ（コミット可能量も考慮）の半分・16 GiBのうち最も小さい値を読み込み開始時の上限にします。固定1 GiBの制限はありません。各素材の読み込み前にも空き容量を再確認し、不足時は必要量と上限までの残りを日本語で表示します。上限を超えたものは読み込まず、現在のセッションを保持します。これは外部プラグインの挙動や消費メモリを制限するサンドボックスではありません。

## 起動時の最近使ったプロジェクト

起動すると最近使ったプロジェクトを表示します。開いた・保存したファイルを新しい順に最大12件記録し、ファイル名と保存場所から選べます。ダブルクリック、Enter、または **選択項目を開く** で開きます。**新規プロジェクト** で新規作成、**プロジェクトを開く...** で別ファイルを選択、**作業画面へ** またはEscで作業画面へ進めます。Projectメニューの **最近使ったプロジェクト** からも開け、**スタート画面...** でこの画面に戻れます。

履歴は `%APPDATA%/Auralis/recent-projects.xml` に保存し、再起動・更新後も引き継ぎます。この版以降に開いた・保存したファイルが対象です。移動・削除された項目は **not found** と表示し、**一覧から外す** で履歴だけを削除できます。プロジェクト本体は削除しません。未保存の変更がある場合は、履歴から開くときも保存確認を表示します。

## プロジェクトを開く

**プロジェクト → 開く project** では、最初に開くプロジェクトを選びます。ファイル選択をキャンセルしても、現在のプロジェクトは変わりません。未保存の変更がある場合は、選択後に **保存／変更を破棄／キャンセル** が出ます。Saveは現在のプロジェクトを保存してから選んだプロジェクトを開き、Discard changesは変更を破棄して開き、Cancelは現在の作業を維持します。未変更の入力欄からフォーカスを外しただけの場合や、再生を止めただけの場合は保存確認を出しません。

## トラック側の設定

各トラックの左欄に、名前の編集、音声入力／MIDIチャンネル選択、REC／MUTE／SOLO／MON、音量・パン、インサート一覧をまとめています。選択していないトラックも、その欄から直接調整できます。インサートは各トラックの **+ 追加** で追加、一覧のダブルクリックで編集画面、右クリックまたは **...** からバイパス・削除・スキャンを行います。MIDIトラックの **MIDI出力** も左欄で設定できます。

右側のトラック設定欄は廃止し、タイムラインを画面の右端まで広げました。LIVE MIDI鍵盤とズームは画面下部です。各トラックの設定欄とクリップは同じ行で一緒に縦スクロールします。入力の変更とインサートの追加・削除は録音を止めてから行ってください。

## 画面の配置

主要な操作は PLAY／STOP／RECORD、Loop／Snap／Metronome、Mixer などDAWで一般的な英語表記にそろえ、メニューや操作説明は日本語で表示します。再生・録音中や各スイッチのON／OFFも文字で確認できます。プロジェクト名の右には未保存の変更を表示します。時間範囲・ループ・範囲録音があるときは、上部の時間範囲欄の右に **範囲を解除** を表示し、再生を止めずに解除できます。

トラックのRECをONにすると **REC ARM**、録音中は **REC LIVE** と表示します。MONがONのトラックは **MON ON** と表示し、ミキサーにもそのトラックのパートが消音されることを示します。音程エディターは **未適用の変更** と **適用** を強調します。音程調整用のLOOP欄も右クリックまたはダブルクリックで解除できます。

上部にはProject・トラック追加・Audio / MIDIと、再生／停止／録音・BPM・Metronome・Loop・Snapをまとめています。読み込み・書き出し・Undo・全音停止はProjectメニュー、MIDIクリップ作成とピアノロールは+ Trackメニューから操作できます。録音のカウントイン・範囲指定とループ時刻はOptionsで開閉し、通常はタイムラインを広く表示します。有効な録音範囲・カウントイン・ループ時刻は、閉じている間も再生位置の下に表示します。

各トラック左側のINSERTSでプラグインを操作します。

## 内蔵イコライザー

トラック左欄、ミキサー、MASTERの **+ 追加 → 内蔵 EQ（音色・周波数調整）...** で追加します。VSTのスキャンや追加インストールは不要です。INSERTSの **Auralis EQ** をダブルクリックすると編集画面を開けます。

4バンドそれぞれで、周波数（20 Hz〜20 kHz）、増減（±24 dB）、Q（効く幅）、有効／無効を設定できます。**ベル** は特定の帯域、**ローシェルフ／ハイシェルフ** は低域／高域全体を調整します。**ローカット／ハイカット** は低域／高域を12 dB/octで削ります。Qを大きくすると狭い帯域や共振が強くなります。機器のサンプルレートで扱える上限を超える周波数は、実際に処理できる範囲へ制限します。

グラフの点を左右にドラッグすると周波数、上下では増減を変更できます。Ctrlで細かく動かし、ホイールでQを調整します。点のダブルクリックで増減を0 dBへ戻します。カット型では上下の増減を使わず、周波数とQで調整します。グラフはEQの周波数特性を表示します。

**出力** でEQ適用後の音量を調整し、**バイパス** で元の音と比較できます。**初期化** でフラットな状態へ戻せます。設定・バンドの有効状態・インサートのバイパスはプロジェクトに保存します。トラックとMASTERに複数追加でき、再生・入力モニター・WAV／MP3書き出しへ反映します。録音ファイルにはEQを焼き込まず元の入力を記録します。追加の先読みバッファは使いません。

## 内蔵チューナーとコンプレッサー

トラック左欄、ミキサー、MASTERの **+ 追加 → 内蔵チューナー／内蔵コンプレッサー** から追加できます。VSTのスキャンは不要です。インサート名をダブルクリックすると編集画面を開きます。どちらも設定をプロジェクトへ保存します。

**チューナー** はギター・ベース・歌声などの単音用です。音名、周波数、基準からのずれ（cent）を表示し、±3 centを緑で示します。検出範囲は25〜1500 Hz、A4の基準は400〜480 Hz（初期値440 Hz）で、入力を自動／左／右から選べます。音程を確認する機能で、音声のピッチ自体は変更しません。マイクやギターの入力を調律するときは、トラック側の **MON** をONにしてください。**ミュートして調律** をONにすると解析を続けながら、そのインサートより先の出力を消音します。MASTERで使うと全体の出力が消音されます。440 Hzボタンは基準だけを戻します。解析は音声処理とは別のスレッドで行い、出力を遅延させません。和音や複数の楽器が混ざった音は対象外です。

**コンプレッサー** は大きな音を抑えて音量差を整えます。しきい値（−60〜0 dB）、比率（1:1〜20:1）、アタック（0.1〜200 ms）、リリース（10〜2000 ms）、ニー（0〜24 dB）、補正音量（−12〜24 dB）、ミックスを調整できます。GRは圧縮している量、IN／OUTは入出力のピークです。グラフで入出力の関係を確認できます。ミックス100%は圧縮音、0%は原音で、中間値は両方を混ぜます。バイパスで原音と比較でき、初期化で標準値へ戻せます。左右の圧縮量を連動させてステレオの定位を保ち、先読みや追加の音声バッファは使いません。リミッターではないため、補正音量を上げすぎた場合の出力超過は防ぎません。

トラック／MASTERの順番に従って再生・入力モニター・WAV／MP3書き出しへ反映します。録音ファイルにはエフェクトを焼き込まず、入力の原音を保存します。チューナーのミュートも書き出しへ反映するので、調律後はOFFに戻してください。

## 内蔵リバーブとディレイ

トラック左欄、ミキサー、MASTERの **+ 追加 → 内蔵リバーブ／内蔵ディレイ** から追加します。VSTのスキャンは不要で、インサート名のダブルクリックで編集画面を開けます。再生・入力モニター・WAV／MP3書き出しに反映し、録音ファイルは原音を保持します。設定とインサートのバイパスはプロジェクトへ保存します。

**リバーブ** はステレオの残響を加えます。広さ、高域減衰、ステレオ幅、プリディレイ（0〜250 ms）、ローカット、ハイカット、ミックス、出力を調整できます。Small room／Hall／Ambientのプリセットから始められます。広さを上げると余韻が長くなり、高域減衰を上げると残響の高音が早く収まります。プリディレイは原音と残響が始まる間隔です。ローカット／ハイカットは残響側だけに適用します。

**ディレイ** は1〜4000 msの反復音を加えます。反復量（0〜90%）、ハイカット、ミックス、出力を調整できます。テンポ同期ではプロジェクトのBPMと音符の長さから時間を決め、全音符〜16分音符、付点8分・付点4分・3連8分に対応します。同期中はミリ秒の直接入力を無効にし、グラフ右上に実際の時間とBPMを表示します。**左右交互** は入力をモノラルにまとめ、反復を左→右へ交互に返します。Slapback／Tempo echo／Ping-pong dottedのプリセットも使えます。時間の変更は短くなめらかにつなぐため、変更中は反復音の音程が動くことがあります。

両方とも **ミックス0%は原音、100%はエフェクト音のみ** です。バイパスで元の音と比較し、初期化で標準設定へ戻せます。グラフは設定値から描いたイメージで、実際の波形ではありません。先読みや原音を遅延させる追加バッファは使いません。

全体の書き出しでは、トラックとMASTERの直列エフェクトの推定余韻を加えた終了位置を初期値にします（最低2秒、余韻の自動追加は最大120秒）。必要に応じてEndを変更できます。時間範囲を選択した場合は選択範囲をそのまま使い、終了時刻を自動延長しません。開始位置より前から続く余韻は、推定余韻の範囲内で直前の音を先に処理して再現します。長い余韻も含めたい場合は、その分まで範囲を広げてください。

## トラックミキサー

上部の **Mixer** または **F3** で、画面下のミキサーを開閉します。音声・MIDIトラックごとに音量フェーダー、左右パン、REC／M／S／MON、音量メーターを表示します。右端のMASTERで全体の出力音量を調整します。トラック数が多い場合は下部を横スクロールでき、MASTERは固定です。

トラック名をクリックすると対象トラックを選択します。タイムライン側のミュート・ソロ、トラック左側の音量・パン、上部のマスター音量と相互に連動します。フェーダーの下の数値を直接入力でき、フェーダーをダブルクリックすると0 dB、パンをダブルクリックすると中央へ戻ります。最下段の-60 dBは無音です。録音中も音量・パン・ミュート・ソロを操作でき、RECの切り替えは無効になります。音量・パン・マスター設定はプロジェクトへ保存します。

## 再生・録音時の画面追従

再生・録音中は、再生バーが画面右端の手前まで進むと、自動で次の区間へスクロールします。画面外の位置から再生した場合や、ループで前へ戻った場合も追従します。録音が長くなってもスクロール可能な範囲を自動で広げます。停止中・カウントイン中は追従しません。

横スクロールバーを手動で動かすと追従を約2秒休止し、ドラッグ操作中も画面を動かしません。Project → Tools → **再生位置を画面で追従** で追従をON／OFFできます。初期状態はONです。

## トラックの移動と高さ調整

トラック名の右の **−** でコンパクトに閉じ、**＋** で閉じる前の高さに戻せます。開閉状態と元の高さもプロジェクトへ保存します。

左欄のトラック番号や余白を上下へドラッグして、トラック全体を並べ替えられます。下端の境界線を上下へドラッグすると、そのトラックだけ高さを64〜480pxで調整できます。小さくしたときは詳細設定を隠し、基本ボタンを残します。順番と高さはプロジェクトに保存します。録音中は並べ替え・高さ変更を止めます。

録音したパートも、タイトルまたは波形を別の音声トラックへドラッグして移動できます。移動先の行を枠で示します。音声パートは音声トラック、MIDIパートはMIDIトラックへ移動します。開始時刻・トリム・音量・素材を保持し、横にも動かした場合は時間位置も移動します。同じトラック内での波形の上下ドラッグはパート音量の調整です。

## PLAYHEAD／RANGEの固定表示

PLAYHEADとRANGEの2段は、トラックを下へ縦スクロールしても上部に固定表示します。固定された段から再生位置の移動・時間範囲選択・Ctrl＋ホイールでのズームを操作できます。横方向の表示位置はタイムラインと同期し、録音中の操作制限も同じです。

## プラグインの用途表示

各トラックの **+ 追加** は、日本語の用途別メニューになっています。各候補に名前・用途の短い説明・メーカーを表示します。音源は音源として区別し、公開カテゴリが大まかな製品は詳細を推測せず「用途未判定」等で表示します。トラック内のインサート名にも種類を添え、マウスを重ねると用途・メーカー・公開カテゴリを確認できます。

FabFilterのPro-Q／Pro-C／Pro-L／Pro-MB／Pro-G／Pro-DS、SocaLabs Gate、MeldaProduction MSuperLooperには、メーカー情報を確認した用途を表示します。参考: https://www.fabfilter.com/products 、https://socalabs.com/effects/gate/ 、https://www.meldaproduction.com/MSuperLooper 。その他はスキャン時に取得したカテゴリに基づく一般的な用途説明です。

## マスターのプラグイン

ミキサー（Mixer／F3）の右端 **マスター** にも **+ 追加** とインサート一覧があります。各トラックの音をミックスした後に、マスターのエフェクトを上から順に処理し、その後でマスター音量を適用します。音源プラグインは対象外です。

一覧のダブルクリックで編集画面、選択後の **...** からバイパス・削除・スキャンを操作できます。用途別メニューと説明も使えます。マスタープラグインは再生とWAV／MP3書き出しに適用され、種類・順番・設定・バイパス状態をプロジェクトへ保存します。録音元のドライ音声には焼き込みません。メトロノームはモニター専用で、マスターエフェクトの後に加えます。

## 基本操作

1. **音声 / MIDI** で入出力デバイス、入力チャンネル、サンプルレート、バッファを指定します。ASIO / Windows Audio / DirectSound に対応します。小さいバッファほど低遅延ですが、安定性は機器次第です。
2. **プロジェクト → 音声を読み込み / MIDI** またはファイルのドラッグで WAV / AIFF / FLAC / MP3 / OGG を読み込みます。複数ファイルは別トラックになります。
3. 各トラック左側の **REC・MUTE・SOLO・MON** で録音待機・ミュート・ソロを切り替えます。MONをONにすると、その音声トラックの録音済みパートを再生せず、入力音だけをモニターします。他トラックは通常どおり再生し、MONをOFFにするとパートの再生が戻ります。MUTEの設定は保持します。WAV／MP3書き出しではMONがONでもパートを含めます。対象トラックを選び直さずに操作でき、ONのボタンは色が変わります。トラックを選択すると、各トラックの左欄で入力・音量・パン・プラグインを調整できます。録音中もMUTE／SOLO／MONは操作でき、RECの切り替えは無効です。
4. **再生 / 停止** で再生・停止。上部の緑色 **再生HEAD** 段をクリック・ドラッグすると、再生バーがマウスに追従して移動します。青色 **RANGE** 段では時間範囲を選択します。Shiftを押している間はSnapに従って拍に吸着します。
5. 波形を横にドラッグして移動、左右端をドラッグしてトリム。トラック間の移動はクリップ上部のタイトル部分をドラッグします。Altを押しながらドラッグすると複製します。
6. **S** で選択クリップを再生位置で分割、**Delete** で削除。右クリックから複製・フェード設定も可能です。
7. **吸着** は1拍単位の吸着。ループ始点・終点（秒）は **詳細** 内で指定します。画面右下のスライダーはズームです。
8. **PROJECT → 保存 project** で保存。音声を `<プロジェクト名>_media` にコピーし、VST3の状態も保存します。このフォルダと `.auralis` をセットで移動してください。保存すると再生は停止します。

`Demo/First light.auralis` は合成音で作ったサンプルプロジェクトです。

## 録音中の波形

音声録音中は、実際に収録した入力の波形を赤いパート内にリアルタイム表示します。Input monitorがOFFでも表示され、選択した入力チャンネルに従います。トラック音量やエフェクト適用前の録音音量を示します。カウントイン・プリロールは含めず、録音位置の遅延補正に合わせて波形が伸びます。STOP後は通常の録音パートの波形へ切り替わります。表示用ピークは録音開始前に領域を確保し、音声処理を描画待ちにしません。

## 音声録音のタイミング補正

機器が報告する入力＋出力の遅延を使い、新しい音声録音を伴奏の位置に自動で合わせます。パンチインでは遅れて届く入力の末尾まで受け取ってから完了し、再生バーはOutで止めます。カウントイン・プリロールにも対応し、MIDI録音や既存パートの位置は変更しません。補正量はProjectメニューの音声診断にサンプル数で表示します。

機器の報告値に誤差がある場合や、プラグイン・外部機器で追加の遅延が発生する場合は、ずれが残ることがあります。演奏中に聴く音の遅れを減らす機能ではありません。通常録音の手動STOPは即座に停止するため、STOP後に到着する入力は収録しません。

## VST3スキャン一覧の保存

スキャンしたプラグインは共通の設定ファイルへ即座に保存し、次の起動やアプリ更新後も一覧に復元します。保存できなかった場合はエラーを表示します。初回起動では、実行ファイルと同じ場所、および同じ親フォルダ内の旧 `Auralis*` フォルダにある `Data/plugins.xml` を重複なく取り込みます。以前の版でスキャンしたプラグインも再スキャンせずに引き継げます。別の場所に置いた旧版の一覧は自動検出しないため、再スキャンしてください。プロジェクトの新規作成・読み込みでスキャン一覧は消えません。

## 選択範囲のリピート

青色のRANGE段のドラッグで時間範囲を選び、**L** または上部の **ループ** をONにします。**再生／Space** で再生すると、その範囲の終点から始点へ繰り返し戻ります。再生バーが範囲外なら、LoopをONにした時点で始点へ移動します。もう一度L／LoopでOFFにでき、選択範囲は残ります。

LoopがONのまま範囲を選び直すと、リピート区間も更新します。時間範囲を選んでいない場合は、Options内のLOOP IN／OUTを使います。設定はプロジェクトに保存します。音声・MIDIとも処理ブロックの途中で正確に折り返し、入力モニターは連続して処理します。録音中はリピートせず、パンチインのOutで停止します。WAV／MP3の書き出しは指定範囲を1回だけ出力します。

## 重なったパートの長さ調整

調整したいパートを選ぶと、他のパートに隠れた端もドラッグできます。完全に隠れている場合は、右クリック → **重なっているパートを選択** で対象を選んでから端をドラッグしてください。選択や長さ調整で再生の優先順位は変わりません。

## 重なったパートの再生

同じトラック内では、重なった区間を **後から録音・追加・複製したパート** が優先して再生します。音声・MIDIとも対応し、新しいパートが無音の区間でも古いパートは鳴らしません。新しいパートの終了後は、残っている古いパートへ戻ります。別トラック同士は従来どおりミックスします。

画面でも新しいパートを手前に表示し、クリックで選択できます。元のパートは削除せず残すので、新しい方を短くしたり削除したりすると古い部分が再び聞こえます。作成順はプロジェクトに保存し、古いパートを分割しただけでは優先順位を変えません。WAV／MP3書き出しにも同じ再生ルールを使います。

## パートの長さ調整（トリム）

通常モード（V）でパートの左右端にマウスを合わせると、左右に伸縮するカーソルになり、端が緑色に強調されます。そのまま左右へドラッグすると不要な先頭・末尾を隠せます。端の少し外側からでもつかめます。

伸ばすと隠した部分を元に戻せます。音声は元ファイルの先頭・末尾までが上限で、元の録音ファイルは変更しません。再生速度・音程・パート音量も保持します。SnapがONなら拍に吸着し、**Shift＋端のドラッグ** は自由な位置で調整します。Ctrl＋Zで1回のドラッグをまとめて戻せます。MIDIパートの端も同じ操作で調整できます。録音中は編集を無効にします。

## 一音ずつの音程エディター

音声パートを **ダブルクリック**、または右クリックの **音程エディター...** で開きます。録音を解析し、ピアノ鍵盤と音ごとのブロック、元の音程と調整後の線を表示します。歌声・ギターの単音やメロディ向けです。

細かいしゃくりやビブラートを編集する場合は、右下の **縦ズーム** で音程方向を0.5〜32倍に拡大できます。倍率の数値入力にも対応します。**Ctrl+Shift+ホイール** はマウス位置の音程を保ちながら縦ズームし、左の鍵盤上では **Ctrl+ホイール** でも同じ操作ができます。拡大時はセント単位の補助目盛りを表示します。最大倍率では1 centが約7 pxになります。スライダーのつまみをダブルクリックすると1倍、**全体表示／F** は通常の縦倍率とパート全体の横表示へ戻します。従来のグリッド上の **Ctrl+ホイール** は横ズームのままです。音や再生バーをドラッグ中は倍率を固定します。

**音程調整専用の範囲ループ** は、時間目盛りの下の **LOOP欄** を左右にドラッグして指定します。範囲を決めると **範囲ループ** がONになり、「再生」または「適用して再生」で指定部分を繰り返します。範囲の両端をドラッグして長さを変えられ、Escで範囲変更を取り消せます。再生バーを動かす時間目盛りとは別の欄です。最短範囲は20 msです。

右上の **範囲ループ** をOFFにすると通常の再生へ戻ります。LOOP欄のダブルクリックで範囲を消します。専用ループはプロジェクト側のループ範囲や録音用の選択範囲を変更せず、書き出しにも適用しません。エディターを閉じる／隠す、プロジェクトを開く、録音へ移ると解除します。範囲はこのエディター内の試聴用で、プロジェクトへは保存しません。パートのトリム等で再解析が必要になった場合は一旦解除し、再解析後は残っている音声範囲へ合わせます。

**緑の音程線を直接編集する場合** は、上部の **カーブ編集** をONにします。線をつかんで上下に動かすと、その周辺の音程だけを滑らかに変えられます。横へなぞると、その部分を描いた形へ置き換えます。水平に引けばビブラートを平らにでき、斜めに引けばしゃくりや音程の上がり下がりを描けます。Ctrlを押すと上下が微調整になります。一度のドラッグは押した音の中で編集し、前後の描いていない部分は保持します。ドラッグ試聴がONなら変更を聴きながら操作できます。

**ブロックがない部分の緑の線**も、カーブ編集をONにして線の近くをつかむと調整できます。短い音や語尾は独立した編集範囲になり、隣の音を動かさずに変更できます。適用・再解析・保存後も保持します。音程線のない無音部分には音程を作りません。

手描きは20 ms単位で点をまとめ、手の細かな揺れを滑らかにします。同じ場所でドラッグを止めても補正は重なりません。平らな線の不要な点は自動で間引き、編集範囲の前後は60 msでなじませます。既存のカーブが細かく波打つ場合は、対象の音を右クリック → **カーブを滑らかに**。速い揺れと不要な点を減らし、遅いビブラートと両端の位置・音程を保ちます。Ctrl+Zで戻せます。音声への反映には **適用** を押してください。

Ctrl+Z／Ctrl+Yでドラッグ単位のUndo／Redo、Escまたはフォーカスを外すと操作中のドラッグだけ取り消します。**適用** で音声へ反映し、カーブはプロジェクトにも保存します。音をまとめて上下に動かす場合はカーブ編集をOFFにします。音の移動・分割・トリム後もカーブを保持します。**音を元へ** で選んだ音のカーブを解除できます。手描きした音に「しゃくりを調整...」を設定すると、その音の手描きカーブをしゃくり設定へ置き換えます。

音をクリックして上下にドラッグすると半音単位、**Ctrl＋ドラッグ** はセント単位で細かく調整します。音の時間位置と長さは動かしません。↑／↓は半音、Ctrl＋↑／↓は1 centずつ調整できます。Ctrl＋クリックや枠で複数の音を選択できます。Ctrl＋ホイールでマウス位置を中心に拡大縮小し、**全体表示／F** で全体へ戻します。

右クリックの **音程を数値指定...** では音名とセントを直接入力できます。検出した音がつながっている場合は、**ここで音を分割** して別々に調整できます。**音を元へ／Delete** は選んだ音の音程を元に戻します。ダブルクリックは最寄りの半音へ合わせます。手動編集は一音あたり元の音程から±12半音までです。

**ドラッグ試聴** がONなら、音を押している間、元の録音を調整した音程でループ試聴できます。上下ドラッグに追従し、離すと停止します。試聴は即時反応のため再生速度を変える方式で、最終的な長さ・声の響きを保持した補正音は適用後に確認してください。試聴中は再生位置を保持します。

再生・録音中は、再生バーが右端に近づくと音程エディターも自動でスクロールします。ループや前の位置へ戻ったときも追従します。音の編集・範囲選択・再生バーのドラッグ中や試聴中は画面を保持し、手動で横スクロールした後は2秒待って追従を再開します。停止中は動きません。Toolsの **再生位置を画面で追従** でタイムラインとまとめてON／OFFできます。

**しゃくりの調整** は、音を右クリック → **しゃくりを調整...** で開きます。**深さ（cent）・長さ（ms）・立ち上がり** をスライダー／数値で変更できます。深さ0で出だしの音程を平らにし、深くすると低い音程から上がる動きを強めます。立ち上がりは1が均等、大きいほど早く上がります。指定した出だしの範囲だけを調整し、後半のビブラートは残します。最大12半音、長さ20〜2000 ms（音の長さまで）です。

**ループ試聴** をONにしたままスライダーを動かすと、調整中のカーブを聴けます。試聴は即時方式なので、最終的な補正音は「設定」→エディターの「適用」で確認してください。「キャンセル」は変更せず試聴を止めます。「しゃくりを調整」をOFFにすると元のしゃくりを保持します。検出で出だしが複数の音へ分かれた場合はCtrl／範囲選択で隣接音を選び、右クリック → **選択音をまとめる** を使ってから調整してください。設定はUndo／Redoとプロジェクト保存に対応し、トリムや音の分割でもしゃくりの開始位置を保持します。「音を元へ」は選んだ音のしゃくり調整も解除します。

編集後は **適用／Ctrl＋Enter** で音声へ反映します。**適用して再生／Space** は反映後に再生バーの位置から再生します。上部の時間目盛りをドラッグして再生位置を指定でき、選択音を変えても再生開始位置は変わりません。未適用の編集はローカルのCtrl＋Z／Ctrl＋Yで戻せます。適用後はプロジェクト側のUndoで戻せます。指定していない音は元の音声を保持し、繰り返し処理する場合も元の録音から作ります。音ごとの設定と分割位置はプロジェクトにも保存します。

未適用の変更がある間は、保存・書き出し・プロジェクト切り替え時にエディターへ戻ります。先に適用するか **変更を破棄** を選んでください。閉じる際も破棄の前に確認します。元パートをトリムするなど解析対象を変えた場合は、未適用の変更を処理してから **再解析** してください。録音中は編集できません。

## 自動の音程補正

音声パートを右クリックして **音程補正...** を開きます。歌声やギターの単音・メロディを、キー／スケールに含まれる最寄りの音へ寄せます。クロマチック・メジャー・ナチュラルマイナーに対応します。コード内の音を一本ずつ補正する機能ではありません。

特定の音へ直す場合は、その音をカットで切り分け、**補正先の音** に目標のノートを指定します。補正量、追従時間、対象にする最大のずれ、基準A4（440／442 Hz等）、声の響きの保持を設定できます。初期値は補正量75%、追従80 ms、最大200 cent、A4=440 Hzです。小さい追従時間ほど速く音程へ寄せます。最大ずれを超えた音や、音程を安定して検出できない部分は補正対象から外します。

適用時は再生を止めてバックグラウンドで解析・処理し、補正済み音声を通常のパートとして再生します。パートの長さ・位置・ゲイン・フェードを保持し、通常の入力モニターに補正の処理を追加しません。120 ms未満の短いパートと録音中の編集には対応しません。

補正済みパートの名前には **[Pitch]** が付きます。右クリックの **音程補正を解除** またはCtrl+Zで戻せます。再適用は元音声から行い、処理を重ねません。プロジェクト保存では元音声・補正済み音声・設定を一緒に保持し、再度開いても解除・再適用できます。WAV／MP3書き出しにも反映します。

音程検出とピッチ同期の波形合成で処理します。トリム後の範囲だけを補正するため、後からパートを伸ばして隠れた部分を出した場合は、必要に応じて再適用してください。

## ノーマライズ

音声パートを右クリックして **ノーマライズ...** を選び、目標ピークを−60〜0 dBFSで指定します（初期値−1 dBFS）。トリム後の範囲を左右チャンネルまとめて測定し、左右のバランスを保ってパート音量を調整します。元の音声ファイルは変えず、Ctrl+Zで戻せます。無音のパートは変更しません。録音中は操作できません。

フェード・トラック音量・プラグイン・マスター処理前のサンプルピークを基準にします。音圧（LUFS）を揃える機能ではありません。補正量が−60〜＋60 dBを超える場合は変更せず、画面下部に理由を表示します。書き出しとプロジェクト保存にも反映します。

## パートごとの音量

音声クリップを選び、**波形部分を上下にドラッグ** すると、そのパートだけ音量を変更できます。上が大きく、下が小さくなります。クリップ上部のdB表示を上下にドラッグしても調整でき、**Ctrlを押しながら** は細かい調整です。範囲は-60〜+60dB、0dBが元の音量です。波形表示も音量に合わせて変わります。

**クリップを右クリック → パートの音量...** ではdB値を直接入力できます。**音量を0 dBに戻す** で元に戻せます。選択やクリックだけでは編集履歴を増やさず、ドラッグはCtrl＋Zで1回の操作として戻せます。

同じトラックの他のクリップや元の録音ファイルは変更せず、再生・WAV／MP3書き出しに反映します。プロジェクト保存・分割・複製でも音量を保持します。MIDIクリップはピアノロールのVelocityを使用してください。

## トラックの削除

左側のトラック名・余白、トラックの空白レーン、またはREC／MUTE／SOLO上を右クリックし、**トラックを削除...** を選びます。確認画面で対象のトラック名を確認して **トラックを削除** を押すと、そのトラックとクリップ・プラグインを削除します。Cancelで中止できます。REC／MUTE／SOLO上の右クリックでは各ボタンの状態を切り替えません。クリップの上は従来のクリップ編集メニューです。

**プロジェクト → 選択トラックを削除** からも同じ確認画面を開けます。録音中は削除できません。

## カット（クリップ分割）

タイムライン左上の固定欄に **選択 V／カット C** を表示します。カットをクリックするか **C** で切り替え、クリップをクリックするとその位置で左右に分割します。現在のモードはボタンの色で確認できます。カットボタンをもう一度クリックするか、**V** またはもう一度Cで通常の選択へ戻ります。トラックを縦スクロールしても操作できます。Project → Toolsからも切り替えられます。

SnapがONなら拍に吸着し、**Shift＋クリック** は自由な位置で切れます。カット位置はオレンジ色の線で表示します。パートやPLAYHEAD／RANGEをクリックすると、ショートカットの入力先をタイムラインへ移します。カット中の **Ctrl＋Z** は分割を取り消し、トラック名を変更しません。トラック名を直接編集中のCtrl＋Zは、文字の編集を取り消します。

選択クリップを再生バー位置で切る場合は **S**。右クリックから **ここで分割**（右クリック位置）／**Cut at playhead**（再生バー位置）も選べます。右側のクリップを選択するので、続けてカットできます。音声・MIDIに対応し、元の素材を保持したまま分割します。Ctrl＋Zで操作単位に戻せます。端・範囲外のカットは変更せず、録音中は使えません。

## ズームと全体表示

メイン画面は右下のズームスライダー、またはタイムライン上のCtrl＋ホイールで拡大・縮小します。最小倍率は0.25ピクセル／秒で、1280〜1400幅では約50〜58分を一度に表示できます。スライダーは低倍率も調整しやすい配分にしています。**F** または **プロジェクト → Fit project to window** で、曲全体と有効な録音・ループ範囲を画面に収めます。スライダーのダブルクリックで標準倍率に戻ります。

ピアノロールもCtrl＋ホイールで大幅に引けます（最小0.125ピクセル／拍）。**F** でクリップ全体を表示します。拡大・縮小中もマウス位置の時刻を保ち、低倍率では目盛りの間隔を自動で広げます。

## メトロノーム

再生操作と同じ段にある **Metronome** でON／OFFを切り替えます。再生・録音中にBPMに合わせて四分音符のクリックを鳴らし、4拍ごとの先頭は高い音で知らせます。停止中は鳴りません。クリックの音量はMasterに従い、録音データやWAV／MP3書き出しには含まれません。ON／OFFはプロジェクトに保存します。

## 範囲選択・パンチイン録音

上部の **詳細** を開き、**カウント in** でOff／1 bar（4拍）／2 bars（8拍）を指定します。RECORDを押すとクリックで数えてから、現在位置で録音を始めます。カウント中は再生位置を保ち、入力は録音しません。MetronomeがOFFでもカウントは聞こえます。STOP／Escでカウントを中止でき、空のテイクは作成しません。

タイムライン上部の **青色のRANGE段をドラッグ** すると時間範囲を青く選択します。通常の選択モード（V）では **Shift＋ドラッグ** でクリップの上からも範囲選択でき、Shift中はグリッドに吸着しません。逆向きのドラッグにも対応します。

**RANGE（時間範囲）の段を右クリック**すると、時間範囲の選択を解除し、**ループと範囲録音もOFF**にします。左側の見出しでも操作でき、トラックを下にスクロールしているときも使えます。プロジェクト → ツール → 時間範囲の選択を解除も同じ動作です。右クリックでは再生位置・再生状態を保持します。Escも範囲・ループ・範囲録音を解除し、従来どおり再生と全音を停止します。録音中は右クリックやメニューから解除できません。

範囲を選んで **P** を押すと、その範囲をパンチインに使います。Options内の **範囲録音** と **In／Out**（秒）からも設定できます。再生バーをInより前に置いてRECORDを押すと、その位置から再生し、Inで録音を開始、Outで自動停止します。再生バーがIn以降ならInから始めます。カウントインとも併用できます。タイムラインには録音範囲を赤く表示します。音声・MIDIとも範囲内だけを新しいテイクとして追加し、既存のクリップは残します。同じトラックで重なった区間は、後から録音・追加したテイクだけを鳴らします。古いクリップは残り、重なっていない部分は再生します。パンチイン設定はプロジェクトに保存します。Pでもう一度OFFにでき、選択範囲は残ります。時間範囲はEsc（同時に全音停止）またはProject → Tools → Clear time selectionで解除します。

## ASIO

**音声 / MIDI → Audio device type → ASIO** を選び、オーディオインターフェースのドライバーを指定します。入力・出力、サンプルレート、バッファサイズを設定し、必要ならデバイスのControl Panelを開いて調整してください。設定は終了時に `Data/audio-device.xml` に保存し、次回起動時に復元します。

使用する機器の64bit ASIOドライバーはメーカー提供のものをインストールしてください。DAWにASIO4ALL等を自動インストールする機能はありません。Audio diagnosticsの入力・出力レイテンシはドライバーの報告値です。プラグインによる遅延や実測値は含みません。

## プチプチ音・処理落ちの確認

0.2.1では、画面描画が音声処理のロックを保持して入力モニターや録音を途切れさせる問題を修正しました。波形のピークは読み込み時に計算し、描画時に元の音声を毎回走査する負荷も削減しました。

画面右下に実際のサンプルレート・バッファ、DSP負荷、XRuns、Skipsを表示します。**PROJECT → 音声の診断** では、デバイス名・ドライバーの報告する入出力レイテンシ・録音の欠落・クリップ回数も確認できます。Reset countersで集計をリセット、Save reportで診断テキストを保存できます。

- **Skips**：編集のロック取得に失敗して音声ブロックを処理できなかった回数。録音していない入力モニター中も数えます。
- **XRuns**：ドライバーが報告した欠落と、コールバックの処理期限超過の合計。ドライバーがすべてのハードウェア側の欠落を報告するとは限りません。
- **DSP**：音声コールバックがバッファの処理時間枠を使っている割合です。

バッファを小さくすると遅延は短くなりますが、処理時間の余裕も減ります。ノイズが残る場合は512→1024など大きくして比較してください。MOTU M Seriesでは、Control Panelの **Use lowest latency safety offsets** をOFFにすることで改善する場合があります。アプリとドライバーのサンプルレートも一致させてください。[MOTU公式マニュアル](https://cdn-data.motu.com/manuals/usb-c-audio/M_Series_User_Guide.pdf)

合成入力を使い、128サンプルの入力モニターと64・128・512サンプルの録音／モニターを描画と同時に動かす回帰テストを追加しています。これは描画との競合による欠落の検証で、実際の機器・プラグイン・OS負荷の組み合わせにおける低遅延性能は別途確認が必要です。

## MIDI録音・ピアノロール

0.2.2では、前の音声ブロックのMIDIイベントが繰り返されて鍵盤の音が止まらなくなる不具合を修正しました。音声処理が編集ロックで一時的に遅れた場合も、未処理のノートオフを次の処理まで保持します。ピアノロールの試聴音は、マウスを離したとき・フォーカスを失ったとき・ウィンドウを閉じたときに止めます。

**プロジェクト → Stop all notes** または **Esc** で、再生／録音を停止し、全音源と外部MIDIの発音、未処理の鍵盤イベントを停止・消去できます。

1. **+ トラック → MIDI・楽器トラック** でMIDIトラックを作ります。
2. **音声 / MIDI** で使うMIDI入力を有効にし、トラック左側で入力チャンネル（Allまたは1〜16）を指定します。
3. 対象トラック左側の **REC（録音待機／ARM）** をONにし、上部の **録音** でMIDIを録音します。**停止** でクリップを確定します。MIDIトラックだけを録音する場合、マイク等の音声入力は不要です。音声出力デバイスは有効にしてください。
4. MIDIクリップをダブルクリック、または **+ トラック → ピアノロールを開く** を選ぶと編集画面を開きます。**+ トラック → 再生位置にMIDIパートを作成** は再生位置に空のMIDIクリップを作成します。MIDIトラックの空白をダブルクリックしても作成できます。
5. 空白をドラッグすると四角で範囲選択できます。Ctrl／Shiftを押しながらノートをクリックすると選択を追加・解除、Ctrl+Aで全選択します。選択中のノートをドラッグすると、まとめて音程・位置を変更できます。右端のドラッグは選択ノートの長さをまとめて変更します。Delete／Backspace、または選択ノート上の右クリックで一括削除します。空白のダブルクリックでノートを追加できます。
6. 上部のVelocity・Chは選択ノートすべてに適用します。ノート未選択時は次に作るノートの初期値になります。Gridで吸着単位を変更し、**Quantize clip / Q** でクリップ内のノート位置と長さを丸めます。**Ctrl+D** は選択ノートを範囲の直後へ複製し、複製した方を選択します。連打すると同じ並びを連続入力できます。範囲選択に含めた前後の休符も複製間隔に反映し、必要ならクリップを延長します。Ctrl+Zで移動・複製・削除を操作単位で戻せます。
7. VST3音源をInsertするとその音源で再生します。音源がない場合は内蔵の簡易サイン波音源で試聴できます。サステイン・ピッチベンド等はイベントとして録音・保存し、VST3音源へ渡します。内蔵音源のピッチベンドには未対応です。
8. `.mid` / `.midi` をImportまたはドラッグして読み込めます。**PROJECT → Export MIDI file** で標準MIDIファイルを書き出せます。WAV書き出しにもMIDIクリップとVST3音源の発音を反映します。

ピアノロール内で **Ctrl＋ホイール** を使うと、マウス位置を中心に横方向へズームします。上部の目盛りをクリック・ドラッグすると再生位置を移動できます。停止中も再生バーを表示し、再生中の移動にも対応します。再生バーはドラッグ中のマウス位置に追従し、通常はグリッドに吸着しません。Shiftを押している間だけGridに吸着します。録音中の再生位置変更は無効です。

MIDIクリップとノートは拍単位で保持するため、BPMの変更で再生タイミングが変わります。音声クリップは秒単位です。MIDIファイルのテンポマップには未対応で、一定テンポとして扱います。空のプロジェクトへの読み込みでは最初のテンポを採用し、既存プロジェクトへの追加ではプロジェクトのBPMを維持します。

同じMIDI入力はARMした各MIDIトラックに録音されます。音声トラックとの同時録音も可能です。ノートオン／オフのタイミング・ベロシティ・チャンネル、CC、ピッチベンド、プログラムチェンジ等を保存します。SysExには未対応です。録音中のチャンネル設定・BPM変更・編集は無効です。

## 外部MIDI出力

**音声 / MIDI** のMIDI出力で送信先を選び、各MIDIトラックの **MIDIを外部出力** を有効にします。出力は1ポートを共有し、各ノートのチャンネルを保って送信します。Mute/Soloにも従います。外部MIDIへの送信とVST3／内蔵音源による発音は並行するので、外部音源だけで使う場合は内蔵音源の音量を下げてください。

オフラインWAV書き出しでは外部MIDIへ送信しません。外部ハードウェア音源の音は、音声入力から別トラックに録音してから書き出してください。

## VST3

1. トラックを選び **エフェクト → ... → VST3を検索 folder**。
2. 通常は `C:\Program Files\Common Files\VST3` を選択します。単体の `.vst3` ファイルやバンドルも選べます。
3. **エフェクト → + 追加** からプラグインを追加。プラグイン一覧のダブルクリックで専用画面、**エフェクト → ... → バイパス** で一時無効化、**エフェクト → ... → エフェクトを削除** で削除します。
4. 上から順に処理します。64bitのステレオ対応VST3エフェクト・音源に対応。VST2/AU/AAX、追加出力、外部サイドチェインには未対応です。
5. 選択中のトラックの音源を画面内鍵盤または外部MIDI入力から演奏できます。外部MIDIは **音声 / MIDI** で有効にします。

検出は別プロセスで実行し、1候補45秒でタイムアウトします。挿入後の処理は本体内なので、プラグインによってはDAW全体が終了する可能性があります。保存時・読み込み時のプラグイン状態と比較し、保存後に設定を変えた場合は閉じる前に保存確認を表示します。プラグインが入っているだけで毎回確認することはありません。

## 録音

1. **+ トラック** で録音先を作成。
2. 入力を指定（Stereo 1+2、またはMono入力番号）。実際に有効にした入力に合わせて指定してください。
3. 録音する各トラック左側の **REC（録音待機／ARM）** を有効化。
4. **録音** で録音、**停止** で確定し、録音開始位置に音声クリップを追加します。

24bitのドライ入力をバックグラウンドでWAVに記録します。インサートはモニター・再生・ミックスに適用し、録音ファイルへは焼き込みません。録音先は `ドキュメント/Auralis/Recordings`。録音をプロジェクト保存する際にはメディアフォルダにもコピーします。

入力モニターは初期状態でOFFです。左のトラック欄またはミキサーの **MON** で切り替えます。録音中も操作でき、音声トラックだけに適用されます。MONボタンの色でON／OFFを確認できます。モニターを使う場合はヘッドホンを使用してください。複数ARMトラックへの同時録音に対応します。入力がない場合は録音を開始しません。

## 書き出し

**プロジェクト → 音声の書き出し (WAV / MP3)** で形式・開始秒・終了秒を指定します。時間範囲を選んでいる場合、その範囲が初期値になります。WAVは16bit PCM／24bit PCM／32bit float、現在のデバイスのサンプルレートに対応します。MP3は128／192／256／320kbpsのステレオに対応し、44.1kHzまたは48kHzへ変換します。エンコーダーを内蔵しているので、追加インストールは不要です。ディレイ・リバーブの余韻を含める場合は終了位置を後ろへ延ばしてください（範囲未選択時の初期値は最終クリップの2秒後）。

Mute/Solo、パン、音量、マスター、VST3処理を反映したオフラインレンダーです。クリップ警告が出たらマスター音量を下げて再出力してください。自動正規化やリミッターはかかりません。

## 初期版の範囲・制限

- オートメーション、バス／センド、テンポマップ、タイムストレッチ、プラグイン遅延補正は未実装です。録音位置は機器が報告する入力＋出力遅延で自動補正しますが、実測校正・手動補正値の設定は未実装です。
- CC編集レーンは未実装です。録音したCC等のイベントは保持し、再生できます。Ctrl+Dの複製対象は選択したノートです。
- オーディオループの折り返しはブロック内の指定サンプル位置で処理します。録音中はループせず、タイムラインを直進します。
- 読み込んだ音声はメモリに保持します。1ファイル最大6400万サンプル（48kHzで約22分）。長い録音はファイルとして残りますが、上限超過の場合はそのままタイムラインに取り込めません。
- 自動バックアップ／自動保存はありません。プロジェクトを定期保存してください。
- プラグインはステレオ対応が必要です。楽器・エフェクトの全製品の互換性を保証するものではありません。
- 自動テストは合成入力で録音経路を検証しています。実マイク、オーディオインターフェースの録音・低遅延性能は利用環境で確認してください。

## ソースからビルド

Visual Studio 2022 C++ Build Tools、Windows SDK、CMake 3.22以上を使用します。

```powershell
./build.ps1
```

JUCE 8.0.6は `vendor/JUCE` に含まれています。CMakeの並列プロセス起動が制限される環境でもビルドできるよう、既定では `--parallel 1` を使用します。

```powershell
# 自動検証（検証用VST3も必要）
./build/Auralis_artefacts/Release/Auralis.exe --self-test C:/absolute/path/to/test-output
```

テスト結果は指定フォルダの `results.txt`。録音のフレーム数・入力選択、ミックス、パン、Mute/Solo、プロジェクト復元、書き出しのサンプル値、VST3による処理と状態復元を確認します。
